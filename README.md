# 仙途 · 青石人间

可玩的 Web 图文修仙原型。玩家创建自己的角色；林晚、周安是世界中的独立 NPC。当前包含四城探索主线、四卷人物剧情、三宗修行、NPC 自主人生、完整人物资料与立绘工作流。最新进度、74项 UI 评审处理状态和实际截图见 [UI 改进与交接](docs/reports/UI-REVIEW-IMPROVEMENTS.md)，本次仓库整理与检查见 [上传记录](docs/reports/GITHUB-SYNC-2026-09-09.md)。历史验收保留在 [V0.1 报告](docs/reports/V01-LOCAL-ACCEPTANCE.md) 与 [维护性改进报告](docs/reports/MAINTAINABILITY-SCALE-MOBILE.md)；当前仍是本地候选版，未完成项以最新交接为准。

## 启动

使用 Node.js 24（最低 22.13.0），依赖以 `package-lock.json` 为准。本轮实际环境为 macOS 26.5.1、Node 26.3.0、npm 11.16.0。

```bash
git clone https://github.com/xianningqixi/xiantu.git
cd xiantu
npm ci
npm run dev:local
```

开发页默认在 http://localhost:3000。固定选项游戏不需要账号、API Key 或云数据库。

```bash
npm run verify
npm run start:local -- --hostname 127.0.0.1 --port 3100
```

生产预览打开 http://127.0.0.1:3100。`verify` 包含 Prettier 格式检查、游戏 strict 类型检查、依赖边界、内容、扩展、AI、存储、回调、规则、实际 UI 价格与扣款一致性、保留 UI 组件测试，以及完整生产构建。每次重新构建后应重启生产服务；静态资源在服务启动时加载。`start:local` 保留 Vinext 渲染与静态服务，并处理本机浏览器／代理发来的完整 URL 请求，防止刷新 404。

## 当前功能

- 游戏整页按阅读与操作重排：桌面顶部合并导航、日期和设置，左侧为紧凑人物状态，中间展开剧情，右侧保留此处人物，底部常用行动压成一条；场景图与文字并排，减少重复标题与空白。手机在剧情和此处人物间切换，行动条可左右滑动。页面保持一屏，长内容在各自区域滚动；人物资料与重绘共用固定高度弹窗，交互和出图不推动整页。

- 地点详情底部行动随地点与人物状态更新：坊市杂务与采买、客栈直接免费学功法、郊野返城、宗门拜访／委托／研习心法，以及修为圆满后的突破准备。查看面板不推进日数；实际行动的耗时与奖励从规则配置读取。

- 三宗修行：苍竹林玉女宗（成年女修、清修守贞）、云梦泽合欢宗（自愿道侣共修）、问道峰全真派（养气、剑术与济世）。到当地点击「拜访」追加两名真实门人，再申请入门、做委托、研习心法；六位门人与玩家共用修炼和突破规则。贡献、灵石报酬、心法加成来自同一份 balance 数据，离宗保留历史。
- NPC 自主人生：主角修炼、等候或旅行时，同地点的空闲 NPC 会结识同道，通过往来增进双向好感与信任、结为朋友；符合门规的普通散修会按性格择宗，花真实路程天数远行，抵达后入门，再做委托、积累贡献和研习心法。事件进入人物自己的经历；主角已知的交友、入门等变化也显示在故人近况、闭关摘要和历程筛选中。日常交往与 NPC 委托以次数和日期范围汇总，固定剧情人物沿用原身份与驻地安排。
- 人物「关系」新增相伴交流、双方自愿结侣、良宵与道侣共修；「经历」可筛选性与亲密经历，以非露骨文字记录。未记载的旧经历保持未知，不推断贞洁状态；已完成的四卷相关经历可回看，玉女宗入门采用个人自陈与守贞誓约。普通寒暄不传播私密事件。

- 一屏创角：桌面并列身份、全身立绘与机缘，手机切换同页面板，开始按钮常驻。姓名、性别、容貌、身材、身高、胸围 A–E 选项、模式、三件法宝与无限资质重掷；创角草稿自动保存及文件导入导出。旧草稿与存档的身体数据保持兼容。
- 玩家与 NPC 支持主动生成全身立绘：先由已配置的 LLM 综合形貌与特征词生成完整提示词，再交给生图模型。重绘复用创角形貌表单，生成后对比新旧图，选择「采用新立绘」或「保留原立绘」；采用时图片与形貌一起保存；「恢复原立绘」可恢复首次重绘前的图片与形貌，刷新后仍可恢复。女性使用所选胸围 A–E 杯型，男性隐藏胸围。NPC 资料展示体貌与真实年龄，女性采用年轻成年驻颜外貌。默认形貌命中已生成图库时直接显示全身图；其他形貌需同时配置文字与生图服务。原生图通道已通过用户提供服务的 gpt-image-2 实际出图及页面采用。
- 头像与立绘分开：100 位基础 NPC 与 23 位四卷居民有独立 512px 头肩头像，按各自立绘逐人取景，保留五官、发饰和衣领细节；列表、地图、同行和资料页放大展示。点击头像直接打开完整立绘，点击姓名继续查看属性。玩家采用新立绘时从压缩前原图同步提取头像，已有缓存可直接派生；无对应立绘的人物保留占位。浏览与图片加载不改时间、随机或存档。
- 统一人物资料：主角与所有 NPC 共用属性、关系、经历、立绘四个页签。点击地图人物、剧情人物立绘／姓名、同行成员或战斗队友即可查看；气血与战斗属性读取当前状态，关系区分双向好感／信任／吸引，可继续查看关系人物；经历展示当前人物自己的生平小传和亲历事件，包含玩家未在场的个人经历；查看不会改变游戏内知情与关系。
- 默认 100 位 NPC 的世界：保留原有 40 人，新增 60 名有独立姓名、身形、小传及美术方向的成年女性；新人物外貌跨 Seed 稳定，资质、修为与位置仍由 Seed 决定；共用修炼／突破、旅行、交往、知情记忆、寿元与死亡生命周期。基础与剧情 NPC 统一去重姓名，旧档保留原始备份，人物 ID、历史和关系保持不变。
- 坊市、客栈、古道、秘境，免费功法与劳务恢复，凡人至筑基，非致命突破失败与合法重试。
- 半开放大地图：四座城镇与落霞村、苍竹林、烟波渡、云梦泽、问道峰、雪松原共十处去处，凡人也可自由往返。点击游历页「地图」呼出大地图，点选地名预览、查看路径与天数，确认启程并保存后自动收起；街巷和真实在场 NPC 保留在游历页，手机地图完整显示十处地点。查看地图、人物与线索不推进时间。
- 八节点主线「残碑寻源」：勘察拓片 → 青石辨纹与旧驿图 → 临江旧账与车辙 → 青岚阵图与旧录 → 霜河旁注与结局选择。各城随时可进入，境界、人物在场、时间与前置证据只限制剧情触发；提前拜访不会跳过主线或领取奖励。
- 《青石十钗》四卷固定融入主线，创角无需勾选：春水（青石）→ 夏夜（临江）→ 秋灯（青岚）→ 冬雪（霜河）。各城先到客舍展开本卷，再沿人物与残碑线索前行；其他人事按在场、修为和日数自然发生。新局含 100 名基础 NPC 与 23 名四卷居民，未到达城镇的人物不会堆入当前场景。
- 三人手动／自动战斗、一项已开放剑诀（其余槽位标明本版未开放）、丹药、防御、撤退、掉落与履约／违约／补偿／重逢。
- Worker 完整事务保存、重复命令保护、跨标签冲突、旧档迁移、备份导出／确认恢复及损坏原档保留。
- 可选的“周安的归途口信”独立支线包；[作者预览](http://127.0.0.1:3100/author)与正式存档隔离。
- 游戏内「AI 模型设置」：创角页右上角和游戏「存档与设置」均可进入，文字与生图模型各只需填写 API Key；服务地址、模型和参数已固定，保存后自动启用，支持测试和确认清除。密钥保存在 Node 服务端私有目录，当前浏览器独立使用。
- 服务端可选 AI 同行交涉：用自然语言协商一套标准条款，含澄清、用户确认和迟到响应作废；不支持自由定价。默认关闭，公开部署的 Origin 白名单和按会话／可信客户端限流配置见 [AI-CONFIG](docs/AI-CONFIG.md)。
- 生产 PWA：代码与图标为离线核心，场景、头像和立绘按浏览进入有界图片缓存；首次在线看到“离线可用”后，可断网重开继续固定剧情；更新需结束当前行动并关闭其他游戏页。
- 手机可折叠状态条保留灵石、目标、同行和法宝；前三个目标定位并高亮实际按钮；即时行动提示、按人物归组的闭关摘要和真实关系变化方向。
- Worker 批量推进最多 30 日，逐日保存后发送轻量进度；支持修炼至圆满、等候指定故人和重要事件暂停。历程可按人物、类型、年份筛选，每页最多 50 条。
- 原九张展示图片约 1.36 MB；默认 Seed 12345 的 40 张 NPC 全身 WebP（21 女、19 男）合计 1,716,912 字节，女性采用高开叉裙、丝袜与高跟鞋。新增 60 名女性各有独立全身 WebP，共 2,181,360 字节；默认 Seed 12345 现有 100 张基础 NPC 立绘（81 女、19 男），新角色立绘跨 Seed 可用，以高开叉、透纱、侧胸剪裁、丝袜和高跟鞋做差异化搭配。另接入《青石十钗》四卷 120 张支线图（含 11 张女角色立绘），新增 WebP 合计 12,301,692 字节。全身图、图集与支线自有图均按需加载／缓存；原始画稿和官方游戏内容锁保持不变。

## 验证

```bash
npx playwright install chromium firefox
npm run test:browser
npm run test:stress
npm run verify:release
```

五 Seed 长模拟单列为 `test:stress`，每局 100 NPC／3650 日，本机整组约 14 分钟。`test:browser` 构建后启动独立生产服务；浏览器测试使用隔离上下文。若未先生成十年存档，单次浏览器测试会明确跳过大档性能项；`verify:release` 先运行压力测试，因此会执行这一项。测试已在启动的服务上执行时使用 `XIANTU_TEST_URL` 和 `test:browser:existing`。

```bash
# macOS / Linux；PowerShell 使用相应的 $env:变量设置方式
PLAYWRIGHT_BROWSER=firefox npm run test:browser:existing
PLAYWRIGHT_CHANNEL=chrome npm run test:portability
```

跨浏览器脚本需先完成 Chrome 的 `story.spec.ts`，读取该脚本生成的独立测试检查点。更多命令、证据位置、备份与故障恢复见 [开发交接](docs/HANDOFF.md)。`npm test`、`build`、`dev` 保留原 Sites 脚手架流程；本地游戏使用上面的命令。

- `content-packs/official-qingshi/`：官方故事、NPC、视觉清单及原图；旧 API 1 内容锁保持兼容。
- `content-packs/guest-roadside/`：独立作者只改内容目录完成的 7 节点支线；归途的待绘视觉槽位继续显示占位。
- `content-packs/shichai-{chunshui,xiaye,qiudeng,dongxue}/`：《青石十钗》四卷，31／31／27／31 张 owned 图片；故事卡片并排显示 CG 与参与者立绘，NPC 列表与详情共享自有立绘。图片接入历史见 [2026-09-08 QA](docs/QA-2026-09-08.md)，当前地图与成长节奏见 [旅程验收](docs/QA-2026-09-08-JOURNEY.md)。
- `content-packs/world-atlas/map.json`：十处大地图地点、郊野文字、坐标与支路天数；郊野可停留、休息、修炼并返回城镇，尚未添加独立 NPC 支线，场景图沿用既有山景。
- `content-packs/main-quest/story.json`：独立版本锁的四章主线数据，纯规则只处理条件与命令。地图、主线和旧档接续验收见 [主线验收](docs/QA-2026-09-08-MAIN-QUEST.md)。
- `content-packs/AUTHORING.md`：API 2 能力、精确依赖、校验及预览流程。`npm run content:prepare` 自动扫描、校验并生成静态登记表及官方模板 ZIP。
- `lib/game/`：按随机、世界生成、日演化、战斗、约定、故事、校验拆分的纯规则；`engine.ts` 保留公共接口。共享数值在 `lib/game/content/balance.json`，`commands.ts` 使用命令处理器表。
- `components/game/`：旅程、侧栏、设置、战利品、历程等独立组件；`content-packs/official-qingshi/ui-presentation.json`：目标与引导展示；`lib/server/`：可选 AI 代理。
- `docs/spec/`：规格基线及逐项结果链接；历史报告保留其当时的状态，以本轮验收报告为准。

存档仅在当前浏览器和来源（域名／端口）内保存。新局初始规则版本为 0.1.4，首次宗门拜访可升至 0.1.5；首次真实推进日数进入 NPC 自主人生规则 0.1.6，旧 0.1.4／0.1.5 存档仅查看或加载不会补造事件。旧 0.1.2／0.1.3 存档经 Worker 备份并升级至开放地图规则；地图升级不补基础 NPC、不改变角色身份、时间、随机和历史。主线使用独立 `campaignLock`；已知旧存档在 Worker 事务中升级主线锁、补入未启用的四卷及其居民并备份原档。原有角色、时间、随机、关系、经历和剧情选择保持原样；新居民从接续日起参与模拟，不补造过去事件。只选过部分卷的旧档保留原章节历史，并可继续尚未经历的城市；已走过的城镇仍可往返。当前 schema 6 新增身形和立绘引用，沿用 schema 5 的紧凑结构：将知情记录按事件索引，完整命令回执保留最近 128 条，另保留累计校验链和全部命令 ID；旧档副本迁移并保留原始备份。五份十年旧档迁移后导出约 4.62–4.65 MB。仍使用世界快照，未实现完整命令日志存档或云同步，历史事件和命令 ID 仍会增长；人生存档导入上限为 16 MiB。换浏览器或端口前导出 JSON，再在新页面确认导入。新局、导入、恢复均保留被替换的旧档；不要用清空浏览器数据修复读档问题。

金丹以上、完整恋爱／道侣、宗门经营、云存档、多人、自动批量人物生图、任意脚本与完整 Mod 编辑器仍在本版之外。当前一个包 ID 只登记一个版本；一般扩展用于新局，不支持进行中存档自由热装卸；四卷固定主线有上述专用接续流程，仅为此前四卷 0.1.0 的四个精确内容锁登记了 0.2.0 地图迁移，保留人物、进度和原档。未知锁会保留原档并提示恢复对应旧构建。未命中支线自有图、全身图库且没有自定义立绘时显示明确占位，头像同步使用明确占位；生成图片独立缓存于浏览器（48 MiB 上限），JSON 存档仅含图片哈希，换浏览器或缓存清理后需要重新生成；roadside 的待绘槽位明确使用占位。本次支线摘要增加原图哈希，所有 API 2 包的锁随之变化；未登记迁移的旧支线存档仍需原构建，官方旧档行为不变。
