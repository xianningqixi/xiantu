# 青石十钗 · 世界观与设计总纲

《青石十钗》是四个独立的 API 2 内容包，共用一套世界观，可任意组合启用。0.2.0 起，选中四卷表示它们存在于世界中，实际剧情随所在地、修为与探索线索逐渐出现：

| 卷 | 目录 | 女角色 | 主题 |
| --- | --- | --- | --- |
| 卷一《春水》 | `shichai-chunshui/` | 苏清晏、顾听澜、温知微 | 欠债的人 |
| 卷二《夏夜》 | `shichai-xiaye/` | 裴姒、沈栖月、柳含烟 | 有主之人 |
| 卷三《秋灯》 | `shichai-qiudeng/` | 闻人霜、江照雪 ＋ 男主主线 | 鼎与炉 |
| 卷四《冬雪》 | `shichai-dongxue/` | 叶疏桐、宋小满、楚莲 | 第一次 |

十一位可攻略女角色，全部为成年人（19—34 岁）。每位配一名真实 NPC 情敌。

## 修仙大世界

游戏里的青石坊市只是**云岚境**的一角。云岚境之外是九州，九州之上是天外。

- **境界**：凡人 → 炼气（一至三层）→ 筑基（初期起）→ 金丹 → 元婴 → 更高。游戏引擎目前只模拟到筑基初期；金丹以上只出现在传闻里（北边渡劫的雷声、乘飞舟过境的真人、天外闭关的老祖）。
- **寿元**：凡人七十，炼气一百二十，筑基一百八。这与引擎的 `npcLifespanDays` 一致。寿元将尽而金丹无望的筑基修士，是本系列大多数反派的动机来源。
- **灵根**：决定资质。纯阴灵根（沈栖月）需要阳属相济才能平衡；无灵根的凡人（叶疏桐）按上古说法可借「阳鼎相济」引气入体；山神血脉（宋小满）与妖血（江照雪）是灵根之外的另一种来路。
- **宗门**：青岚宗（九重山门、内门外门、执事、长老、刑堂、禁地寒潭）、归云门（剑修、剑冢、剑心）。散修游离于宗门之外，靠护送、猎妖、行商为生。
- **妖**：山魈、雪狼、雪妖是妖兽；白狐化形的白无咎是妖修。妖丹可换灵石。妖域入口是白骨门。妖气缠身的人（韩铁衣）回不了人间。
- **法宝与丹药**：本命玉、剑穗、山神铜牌、旧玉扣是信物；回春丹、突破丹、凝元草沿用引擎的经济规则。
- **双修与采补**：修仙大世界最古老的两种关系。**采补**是一方从另一方身上取走阴元或阳元续命增修，被采的一方叫**炉**或**鼎**，采的一方叫**采补者**。**既济**是本系列的核心设定：「非采非予，两不相欠」，两个人一起把失去的东西找回来。
- **心魔与道心**：筑基修士的心魔是「知道自己在做什么，却停不下来」。三页残卷的「问己心」是全系列的题眼。

## 既济诀：四卷共用的核心反转

- 卷一、卷二、卷四里，男主用「既济之法」帮女角色解禁制、逆采补、引气入体。文本里它是善的。
- 卷三揭露：男主手里的《既济诀》是合欢宗的**牵丝引**。男主是**阳鼎**，每一位与他合修的女子都是**炉**，两人的阴元阳元都顺着金线流向游方老道玄虚子。男主以为在救人，其实一直在替人采。
- 卷三主线让男主选择：烧诀（不再有新线）或**逆炼**（把采变成真正的既济，剪线并把流走的东西还回去）。
- 四卷可独立启用；同时启用时，主角按青石坊市→临江城→青岚山城→霜河城的路线成长。单独启用卷三仍可在满足成长与探索门槛后抵达山城，揭露对没玩过的卷形成预警。

## 每位女角色的固定结构（12 节点、10 标记）

`meet` → `meet-again`（二次机会）→ `bond`（揭开她的困境）→ `spark`（第一次身体接触）→ `rival`／变体（**争**或**让**）／`rival-gone` → `lost`（被夺，R18 留空）｜`night`（初夜，R18 留空）→ `dual`（双修成长，R18 留空，本线反转在此揭露）→ `vow`（道侣／知己）；`mourn` 身故收束。

## NTR／绿帽元素的处理

- **玩家被夺（绿帽）**：每条线的 `rival` 节点选「让」即进入 `lost`。玩家在门外、墙外、村口、刑堂外听见或看见，从不进入房内视角。文本落在玩家的悔恨与自我认知上，不落在羞辱女角色上。卷四楚莲线把这一点推到极致：男主在故事开始前已被夺过一次。
- **玩家夺人（反向）**：卷二三位女角色名义上都属于别人，卷一苏清晏已定亲，卷四宋小满已定亲。情敌里有真正的恶人（崔九章、严孤鹤、白无咎、沈万山），也有好人（陆青遥、王虎）。好人情敌的被夺结局不写房内，写「她过得好」。
- 引擎层面，被夺只写入本包标记与玩家单方经历，不改变任何人的生死、数值、关系。

## 与官方主线的联动

- 玩家在官方主线对林晚**违约**（`official.outcome = breached`）：顾听澜、沈栖月、江照雪、宋小满的情敌会当众揭发，她们只给一次机会。
- 玩家对林晚**履约**（`fulfilled`）：闻人霜线里崔九章以宗门重信为由让步，实为试探。
- 玩家灵石充足：温知微（60）、裴姒（100）、楚莲（60）线出现以灵石为底气的谈判变体，均为文字，不扣款。
- 玩家尚是凡人（`player.manual = false`）：柳含烟、叶疏桐线出现「凡人」羞辱变体。

## 留给作者的两项工作

1. 所有 `〔R18 段落待补 · 编号 XX〕`：每卷 outline.md 里有要点表。编号规则：卷代号-角色代号-01（初夜）/ 02（双修）/ NTR（被夺）。
2. 图片接入已完成：四卷 120 张自有图与 11 位女角色立绘已通过 `art/manifest.json`、`owned` 视觉槽位接入故事卡片和 NPC 展示。原 PNG、提示词与故事正文不变，验收见各卷 acceptance.md 与 [2026-09-08 QA](../docs/QA-2026-09-08.md)。
3. 十一位女角色统一为**美腿、丝袜、高跟、高开叉**造型：每卷 art-prompts.md 的「女角色统一造型」表给出各人配色（袜色、鞋款、开叉高度），立绘与她出现的所有 CG 必须保持一致；提示词里已逐图写入。

## 协议限制与已知取舍

- 引擎没有 `player.sex` 事实，文本按男主书写，无法在协议层强制。加一行 `facts` 即可支持，见 `lib/game/content-story.ts` 与 `extension-contract.mjs`。
- 每个节点任一选择即消费，只有相识节点有二次机会。若希望每个阶段都可「稍后再说」，需要引擎提供不消费的退出，或作者为每个阶段再加一个标记与节点（会超出 40 节点上限）。
- 情敌与女角色只在所属城镇的地点间往来，每七日回访各自常驻处；突破和队伍占用优先。人物在场才触发交谈，不会跨城混入开局。
- 文本里的修为增长、寿元、采痕都是叙事，引擎数值只由正常修炼、突破、寿元规则决定。

## 当前游戏中的旅程

| 地域与卷 | 开始条件 | 前往下一城 |
| --- | --- | --- |
| 青石坊市 · 春水 | 炼气一层，在听雨客栈问讯 | 炼气二层、主线「旧驿图上的去处」，3 日至临江 |
| 临江城 · 夏夜 | 到临江听潮客栈问讯 | 炼气三层、主线「退水后的车辙」，4 日至青岚 |
| 青岚山城 · 秋灯 | 到山城客舍问讯 | 筑基、主线「被改过的阵眼」，5 日至霜河 |
| 霜河城 · 冬雪 | 到当地客舍问讯 | 可留居或循原路返回 |

每卷场景之间至少两日，深入关系阶段另需成长；远行线索显示在「眼下之事」与城门道路卡中。一次只展示当前可参与的故事。剧情正文和原画没有因此改写；上述规则取代早期将四卷同时列在游历页的方式。正常浏览器路径和规则夹具分开记录于 [旅程验收](../docs/QA-2026-09-08-JOURNEY.md)。


## 地图贯穿主线：残碑寻源

玩家的共同旅程是追查旧阵引走各地灵气的缘由。青石拓片是起点，周安提供旧驿图线索；临江的裴姒保存商队货账；青岚的江照雪提供猎人阵图；霜河的楚莲帮助核对藏书旁注。四章各有一次人物对话和一次实地核查，共八个节点。最终由玩家选择封存方法交各地核查，或公开拓本。结局保存调查和选择记录；不宣称已经数值性地修复世界灵气。

「残碑寻源」负责指引旅行与成长，四卷人物故事负责当地相逢。主角不需要完成固定数量的恋爱或支线才能离城。地图列出本城地点与实际在场人物，未到达城镇的人物不会混入当前城市。对话需人到场、调查需日数经过；已选主线优先显示，完成或条件尚未满足时仍可处理当地故事。
