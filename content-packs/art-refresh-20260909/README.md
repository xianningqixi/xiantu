# 2026-09-09 展示美术更新

本目录只维护展示素材。`catalog.json` 将审核后的图片关联到既有图片 URL、人物或地点，`art/images/` 保存实际用于发布的完整尺寸 WebP。原官方包、四卷内容包、人物定义和原画继续保留。

默认生图模型为配置渠道提供的 `gpt-image-2.5-flare`；主线与宗门人物使用 `gpt-image-2.5-sunburst` 继续精修。模型名是请求给渠道的标识，不代表独立验证了渠道内部的底层模型身份。

`scripts/prepare-content.mjs` 先验证原内容锁与旧头像，再由 `scripts/prepare-cosmetic-art.mjs` 验证本目录的文件摘要、尺寸、人物对应与头像取景。已有立绘沿用原外貌匹配规则，只有新增的六位固定宗门门人使用独立人物映射。地点图按地点 ID 查询。构建派生物不再次压缩已审核的 WebP；头像从同一立绘的人工审核取景生成 512×512 图片。

新增图片不纳入 PWA 首次安装的核心预缓存，进入相关页面时才加载。加载、放大、头像切换与恢复展示不修改世界时间、随机、身份、关系或奖励。玩家自己生成并采用的图片仍优先显示。

逐图文件、提示词来源、精修次数与验收记录见本目录的 `review.json`、`prompts.json` 及 [更新报告](../../docs/reports/ART-REFRESH-2026-09-09.md)。原始 PNG 和中间迭代保存在本地 `output/imagegen/refresh-20260909/`，不将服务日志或密钥提交到 Git。
