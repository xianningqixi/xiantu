# 人物头像

123 位已有独立立绘的 NPC 的展示资源，与人物身份、世界规则、故事内容锁和存档分离。

`base.json`（原40人）、`expanded.json`（41—80）、`remaining.json`（81—100及23位剧情人物）记录人物 ID、当前立绘 URL／SHA-256、头像文件／SHA-256与逐人头肩取景。`crop` 的像素坐标对应 `sourceWidth`／`sourceHeight`；存在高清原稿时另记 `derivationSource`、`derivationSha256`。高清原稿路径是制作溯源，构建只依赖本目录头像及正式立绘，不要求本机 outputs 文件。

头像为 512×512 WebP，quality 92，Lanczos 缩放并温和锐化。基础40人从现有立绘提取；后60人从已核实对应当前立绘的高清原稿提取；剧情23人从包内原图提取。脸、发饰与衣领逐张取景并检查，保留原人物身份，不重绘五官。没有对应立绘的新增人物使用占位。

`npm run content:prepare` 全量检查人物到原图的映射、原图/头像摘要、裁切边界、尺寸、唯一性与覆盖范围，再生成 `lib/game/content/avatars.json` 与按需加载的展示资源。替换立绘时必须同步重新制作对应头像，不允许旧头像静默匹配新立绘。

玩家与游戏内重绘采用浏览器独立图片缓存：从新立绘压缩前的图片提取512px头肩头像；旧缓存没有头像时按需派生。图片处理不发送世界写入命令。
