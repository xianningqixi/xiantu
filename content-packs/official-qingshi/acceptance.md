# 替换内容验收单

由接手作者和开发者在交付时填写版本、修改范围及结果。

## 自动检查

- `npm run content:prepare`：JSON 结构、重复 ID、事实类型、保留标记、效果类型、角色身份、视觉引用和图片存在性通过；ZIP 与运行内容同源。
- `npm run typecheck:game`、`npm run test:content`：内容载入、实际换文案／图片映射、扩展节点、错误内容拒绝等测试通过。
- `npm run test:game`：世界确定性、命令原子性、故事流程与历史等检查通过。仅改文字／图片时可在开发者说明下只运行相关用例；更改规则须运行相关规则测试。
- `npm run build`：可构建，并包含模板 ZIP 与图片资源。

## 人工试玩

- 在新局中输入自己的姓名并选性别，人物面板属于玩家；林晚或其替换者只在 NPC 面板出现。
- 不改引擎／组件，只替换内容正文、选项文字、图片映射后，网页显示修改结果。
- 新增一个接口文档中的标记节点，满足条件时出现，选择后退出候选。
- 依次确认相识、领功法、约定、三人探索、战后返程；分别试玩履约与违约后至少三日重逢。
- 存档重开后身份、进度、事件、关系一致；快速重复操作不重复给予结果。
- NPC 缺席或死亡时相关事件不强行出现；仍可在客栈领取功法。
- 桌面和手机图片裁切合理；人为阻断一张图时仍能阅读和选择。
- 从创建页或设置下载 ZIP，核对本次版本、大纲、实际 JSON、图片和完整性记录。

## 内容升级检查

更新前导出旧局。更新运行内容后旧局应明确提示不兼容，旧数据仍保留；不能静默清空、改写 NPC 身份或迁移旧事件。完整备份应包括旧网页内容版本与存档。

本单区分自动检查与人工试玩。自动测试通过不代表所有浏览器操作已经实测；交付记录应说明实际完成的范围。
