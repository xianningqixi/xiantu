# 青石十钗 · NPC 补充立绘

补齐四卷原先没有独立全身图的 12 位男性 NPC：齐珩、卫岑、郑百川、沈万山、陆青遥、韩铁衣、崔九章、白无咎、玄虚子、叶承、王虎、严孤鹤。

`catalog.json` 按现有角色 ID 绑定原 PNG，保存尺寸与 SHA-256；`art/images/` 保存 12 张 1024×1536 全身立绘。`art-prompts.json` 保存每张图实际使用的完整提示词、剧情参考图与输出路径。图片经用户已配置的 gpt-image-2 服务及 imagegen CLI 的 edit 模式生成，每张以该 NPC 的原剧情图作为身份和画风参考。齐珩的参考图只露出背面，正脸按其成年角色设定补绘。齐珩、白无咎、严孤鹤的服务输出为 1023×1537，最终统一到 1024×1536；其余图片尺寸未调整。

这是独立的展示资源目录，没有可执行支线 manifest，不修改原四卷的定义、故事、图片或内容锁。`extensionPortrait` 仅在已登记角色没有原专属立绘时使用此映射；玩家与未知角色不会命中。NPC 列表、详情及既有立绘消费者共享同一资源入口，浏览器缓存中的用户自定义立绘仍优先。

`npm run content:prepare` 校验角色存在、原专属图冲突、路径、PNG 尺寸、摘要及重复 URL，并生成按需加载的 WebP。这 12 张 WebP 共 624,512 字节，不加入 PWA 核心预缓存。图片读取不发送世界命令，也不改存档、时间、资源、记忆或随机流。
