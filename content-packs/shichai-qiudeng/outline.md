# 青石十钗 · 卷三《秋灯》

本卷主题：**鼎与炉**。修仙大世界里最古老的两种身份：被采的人，和替人采的人。本卷揭开四卷共用的「既济双修」的真相：玩家手里的《既济诀》是合欢宗的牵丝引，玩家是阳鼎，每一位与他合修的女子都是炉，两人的东西都顺着金线流向游方老道玄虚子。玩家在前两卷里以为自己在救人，其实一直在替人采。

世界观见 [SHICHAI-WORLD.md](../SHICHAI-WORLD.md)。

## 男主主线（6 节点）

| 节点 | 内容 | 关键选择 |

| `main.scroll` | 客栈角落，玄虚子递出全本《既济诀》，称玩家是万中无一的阳鼎之体 | 接／拒 |

| `main.choice` | 溪边火折与丹田：烧诀（不再有新线）或**逆炼**（把采变成济，剪线并把流走的东西还回去；记标记 `reversed`） | 逆炼／烧 |
| `main.duel` | 古道秋叶悬停，玄虚子索线 | 剪断／断线放他走 |
| `main.gone` | 玄虚子身故的收束 | — |

`feign` 与 `reversed` 目前只在文本里改变对峙的说法，不改变引擎数值。玄虚子是真实 NPC（炼气三层，66 岁），可能在主线完成前自然身故。

- 闻人霜「守信」：玩家在官方主线对林晚**履约**时，崔九章以宗门重信为由让步，实为试探。
