# 游戏内 AI 模型设置

创角页右上角有 **AI 模型设置**；进入游戏后，点右上角 **存档与设置 → AI 模型设置**。其中「LLM 文字模型」和「生图模型」分别填写启用状态、服务地址（Base URL）、模型 ID、API Key。地址为公网 HTTP／HTTPS 接口根地址，例如 `https://api.example.com/v1`，不要填写完整的 `/chat/completions` 或 `/images/generations` 路径。

1. 填写服务商提供的地址、模型 ID 和自己的密钥，点击「保存配置」，立即生效，无需重启服务。
2. LLM 支持 OpenAI 兼容 Chat Completions，保存后用于立绘提示词构思及现有同行交涉；同行交涉另需严格 JSON Schema。可点「测试连接」验证交涉请求及响应格式。
3. 生图支持 OpenAI 兼容 Images API。点「测试生图（1 张）」发送一条固定山水画提示，显示生成图片的预览；支持 `b64_json` 或公网 HTTP／HTTPS 图片 URL 响应。测试图不进入人生存档；角色立绘使用创角页或人物资料里的独立「随机生成立绘」按钮。
4. 高级选项可改等待时间；LLM 为 1—30 秒、100—8192 回复 Token，生图为 1—120 秒。Token 上限控制最大输出预算，不要求模型每次用满。测试可能产生服务商费用，仅由主动点击发起，没有自动重试，不推进游戏日。
5. 保存后不回显密钥，留空表示保留当前个人密钥；换服务地址必须重新填写。点「清除个人配置并关闭」只清除当前模型，不影响另一模型或游戏存档。默认服务的密钥不能复制为自定义服务凭证。

两页同时修改会检测 revision 冲突，提示重新读取，避免旧页面覆盖新配置。关闭弹窗／取消测试会丢弃迟到结果；测试不自动保存正在编辑的配置。

## 角色全身立绘

同时配置并启用 LLM 文字模型与生图模型后，在创角页「全身立绘」面板、游戏「故人 → 人物资料」中点「随机生成立绘」。服务端先让文字模型综合形貌生成完整中文提示词，再把该结果交给生图模型；文字模型未配置、返回空白／不完整内容、拒绝或超时时，不调用生图模型，也不回退到固定拼接提示词。生图服务需要支持 `1024x1536` 的 Images API 竖图。每个模型会话同一时间只处理一条完整生成流程，每分钟最多六次，无自动重试。两个模型分别遵循已配置的超时，页面总等待上限 165 秒；取消、修改形貌或切换人物会中止旧请求，迟到结果不采用。

文字模型读取当前性别、成年外貌年龄、容貌、发式、衣着、身材、身高和自定义立绘特征。女性额外读取所选胸围 A–E 杯型；男性创角隐藏胸围选项，生成时忽略旧资料中的杯型。旧存档保留的胸腰臀厘米数据不送入立绘提示词。女性默认特征为高开叉裙、丝袜美腿、高跟鞋，可在输入框完整改写；文字模型按用户特征设计服装、材质、配色与姿态，未指定处才参考美术方向。`portrait-directions.json` 包含林晚、周安及 54 套可组合的造型元素，只作为文字模型的美术参考。固定 NPC 与玩家身份分离，方向选择不消耗世界随机流；文本约束无法保证不同服务商每次生成的面孔完全一致。

图片解码后压缩为最大 640×960 WebP，先完整写入独立的 `xiantu-portrait-assets` IndexedDB（总计 48 MiB，超限淘汰最早缓存），之后创角草稿或 Worker 命令才绑定图片 SHA-256 引用。失败不确认采用；换图不推进日期、不重抽游戏随机、不增加资源。世界 schema 6 含身形和图片引用，旧存档在副本上迁移并保留原件。

人生 JSON 不内嵌图片；换浏览器、来源或图片缓存被清理后显示缺失提示，可重新生成。生成图全身展示使用 contain，不裁切头脚；既没有匹配预制图也没有自定义图时使用明确占位，旧列表缩略图不作为已完成的全身素材。已通过用户指定服务的 gpt-image-2 实际生成林晚全身图，并完成浏览器采用；批量默认 NPC 图见 `art/portraits/catalog.json` 的实际已生成条目。默认图库按完整形貌匹配，玩家不会误用 NPC 图；其他 Seed 或修改后的体貌可主动生成。预制全身图按需加载，不加入首次 PWA 预缓存，最近 64 张已浏览图片可离线复用。

## 保存范围与本地部署

个人模型配置按浏览器隔离。浏览器只保存一枚随机 HttpOnly、SameSite=Strict 的访问 cookie；API Key 保存在 Node 服务端私有文件，目录权限 0700、文件权限 0600。读取接口只返回模型信息和 `hasKey` 状态，不返回密钥；不会写入 localStorage、IndexedDB、游戏导出、前端构建或默认日志。

默认目录为项目下 `.xiantu-private/ai-settings/`，已被 Git、Prettier 和开发静态文件访问排除。可用 `XIANTU_AI_SETTINGS_DIR` 指向服务进程可写的持久目录。文件以访问 cookie 的 SHA-256 和模型类型命名，单个 Node 服务内串行写入，临时文件替换完成后才确认保存。保留私有目录和浏览器 cookie 后，重启服务仍可读取；换浏览器／清除 cookie 后需重新配置，不随游戏 JSON 导入迁移。

此个人配置适配器需要 **Node 服务及持久磁盘**。Cloudflare Workers 等无持久磁盘环境应另接私有持久存储后再开放个人配置；当前未部署这一适配。多实例同时修改需要共享存储及对应并发控制，不能让多个进程共写此本地文件目录。私有文件包含密钥，应按凭证管理，不放进静态目录或共享游戏资料。

模型请求由本站服务端发送。个人配置接口核对 Origin、字段与体积；上游允许公网 HTTP／HTTPS，拒绝本机、内网、元数据地址、URL 内账号和跳转。实际请求在解析全部 DNS 地址后检查并固定连接目标，HTTPS 保留 TLS 主机名验证；下载生图 URL 不携带模型密钥。测试每个配置会话每分钟最多 6 次，生图最多一张并限制响应体积。此隔离不等同于公网账号认证或多实例统一配额。

## 站点默认配置

尚无个人配置时，可以使用原有环境变量提供站点默认服务。个人配置优先；用户明确关闭后不会回退并偷偷调用站点默认模型。固定选项无需任何 AI 配置。

`.env.production.local`、`.env.local`、`.env.production`、`.env` 按优先顺序加载；现有进程变量优先。修改环境文件需要重启，游戏内保存个人配置不需要重启。密钥不要写进仓库、聊天或启动命令明文参数。

| 变量 | 说明 |
| --- | --- |
| XIANTU_AI_KEY | 默认 LLM API 密钥，缺省禁用 |
| XIANTU_AI_BASE_URL | 默认 LLM 的公网 HTTP／HTTPS OpenAI 兼容端点，缺省 `https://api.openai.com/v1` |
| XIANTU_AI_MODEL | 默认 LLM 模型 ID，需支持 Chat Completions 严格 JSON Schema |
| XIANTU_AI_TIMEOUT_MS | LLM 等待时间 1000—30000，默认 10000 |
| XIANTU_AI_MAX_TOKENS | 回复上限 100—8192，缺省 800；本机 GPT-5.6 Sol 已设为 8192 |
| XIANTU_IMAGE_KEY | 默认生图 API 密钥，缺省禁用 |
| XIANTU_IMAGE_BASE_URL | 默认生图公网 HTTP／HTTPS 兼容端点，缺省 `https://api.openai.com/v1` |
| XIANTU_IMAGE_MODEL | 默认生图模型 ID |
| XIANTU_PROVIDER_DNS | 缺省使用系统 DNS；本机代理返回 198.18.* 假地址时可设 `google`，经固定公共 HTTPS DNS 获取记录，继续检查全部地址并固定连接，不转发模型密钥给 DNS |
| XIANTU_AI_SETTINGS_DIR | 个人配置私有持久目录，默认 `.xiantu-private/ai-settings/` |
| XIANTU_ALLOWED_ORIGINS | 上线必填，逗号分隔完整游戏来源，例如 `https://game.example.com`；反向代理内部 URL 不参与比较。缺省仅允许本机来源 |
| XIANTU_TRUST_CF_IP | 只有源站不能被绕过、Cloudflare 覆盖 IP 头时才设 `1`；否则使用签名会话限流 |
| XIANTU_AI_MOCK | 仅本地开发设 `1` 启用默认 LLM 固定测试回应，页面标注“本地测试回应”；已保存个人配置优先，连接测试不会使用 mock 冒充成功 |

## 当前交涉范围与验收

LLM 只把自然语言整理为一套标准约定：玩家、林晚、周安三人同行，第一株凝元草归林晚，其余归玩家，路费读取 balance 配置（当前 2 灵石）。不支持自由定价或其他分配。浏览器交涉请求只传游戏上下文，不逐次携带密钥或任意上游参数；服务端读取当前浏览器已保存配置或站点默认配置。

模型可提出 invite / counter_offer / accept / reject / clarify。玩家明确确认后，Worker 再校验存档、revision、身份、在场、生死、队伍、资源和承诺。同一提案只能采用一次，历史不重新调用模型。等待、阅读、取消和错误均不推进时间。

原交涉限额为每签名会话或可信 CF IP 每分钟 6 次；请求体 16 KiB、回复 64 KiB，无自动重试。匿名会话限流仍是进程内状态，不能替代公网身份、总预算和共享配额。

`npm run test:portraits` 覆盖体貌确定性、旧档迁移、零日采用、生图参数与取消；`tests/browser/portraits.spec.ts` 验证响应式创角、图片缓存失败与实际 Worker 保存（生图响应为测试夹具）。

`npm run test:models` 覆盖私有保存、两模型／玩家隔离、密钥不回传、更换地址保护、并发覆盖拒绝、严格格式测试、两种生图响应及内网／跳转拒绝；`tests/browser/model-settings.spec.ts` 验证真实配置 API、游戏入口、刷新恢复与移动端交互。自动回归中的付费模型调用使用固定响应；另已通过用户指定的公网 HTTP 服务完成 gpt-image-2 实际出图及浏览器采用，并生成默认 Seed 12345 的 40 张 NPC 全身素材。真实 LLM 供应方仍未验证，完整烟测记录方式保留在 `docs/reports/AI-SMOKE.md`。
