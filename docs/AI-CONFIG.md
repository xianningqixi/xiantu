# 可选的自由交涉

无配置时仍可用固定选项完成青石篇。当前自由交涉仅处理林晚的下一次秘境同行条款，不能任意改变世界。浏览器只向本站 `/api/negotiation` 请求，凭证和上游地址只由服务端读取，不能从页面传入。等待、取消和错误均不推进游戏日。

服务启动环境可设置如下变量；密钥通过本地未跟踪的环境文件或安全的环境管理工具提供，不要写进仓库、聊天或启动命令明文参数。

| 变量 | 说明 |
| --- | --- |
| XIANTU_AI_KEY | 上游 API 密钥，缺省为禁用 |
| XIANTU_AI_BASE_URL | HTTPS OpenAI 兼容端点，默认 `https://api.openai.com/v1`；不允许 URL 内凭证、查询或片段 |
| XIANTU_AI_MODEL | 操作者明确选择的模型 ID，需支持 Chat Completions 严格 JSON Schema |
| XIANTU_AI_TIMEOUT_MS | 1000—30000，默认 10000 |
| XIANTU_AI_MAX_TOKENS | 100—1500，默认 800 |
| XIANTU_AI_MOCK | 仅本地开发设为 `1` 启用固定测试回应；页面显示“本地测试回应” |

此本地原型代理按进程全局每分钟至多 6 个请求，请求体 16 KiB、上游响应 64 KiB，不重试，不回显供应方错误、凭证或请求正文。不将本地限流宣称为多副本公网认证方案；公开部署前应由具体部署任务接入身份和统一配额。

模型提出 invite / counter_offer / accept / reject / clarify。条款含糊时无可提交动作，确认按钮只针对完整的标准条款。正式 Worker 再校验存档、revision、目标身份、在场、生死、队伍、资源、NPC 接受资格和冲突承诺。相同提案只能采用一次，正文及条款留档；历史展示不再请求模型。

当前实现与固定 mock 的成功、格式错误、超时、取消、限流、越权和迟到路径应分别记录。真实供应方尚未配置，不能把 mock 的通过记成供应方烟测。启用真实服务后，按 `docs/reports/AI-SMOKE.md` 记录一次含糊提议与一次完整提议的实际等待、请求数和结果。
