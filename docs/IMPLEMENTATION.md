## 原型取舍

使用 Sites 提供的 React／Vinext／Vite 工程以适配平台发布，纯规则和图文内容仍独立于框架。此前 React + Vite 的分层原则保持，运行包装不是另建一套 Unity 客户端。

配图采用两张古风像素场景和一张非像素林晚立绘。客栈使用坊市外景作地点氛围配图，古道复用秘境山景；不把复用图声称为四张独立场景图。

NPC 与玩家共用修为收益、阈值、突破概率和突破结果处理；NPC 筑基占用三日并记录进行中的尝试。非致命石傀遭遇不会触发复杂模式终局；复杂模式保留寿元终局，更多危险遭遇尚未开放。

## 本轮新增：可替换内容模板

实际运行的 8 个故事节点、4 个地点、2 位 NPC 初值、开场与战后过场已从组件／规则中抽出，放到 `content-packs/official-qingshi`。故事引用视觉 ID；素材清单和三张原图独立保存。角色显示名用占位符从本局人物读取，玩家身份不会从 NPC 模板创建。

内容准备脚本进行结构、条件、角色和视觉引用检查，复制图片，生成 SHA-256 内容锁及下载 ZIP。创角页与设置均提供模板下载。包中同时附大纲、作者说明、接口表、图片来源说明和验收单。只支持已声明的事实与四种剧情效果，不宣称完整 Mod 安装器已完成。

模板接入后完成：7 项内容测试、11 项相关规则回归、游戏类型检查与正式构建，均通过。新增节点测试使用已载入的内容数据和声明标记，未更改引擎规则；不等同于完整作者浏览器试玩。之前通过的 100 NPC／3,650 日长模拟不因本次纯内容抽取再次重复运行。ZIP 校验通过：16 个文件与内容目录逐字节一致，3 张图与静态副本及 SHA-256 一致。浏览器端到端验证仍未执行。
