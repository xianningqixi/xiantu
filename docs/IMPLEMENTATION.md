## 原型取舍

使用 Sites 提供的 React／Vinext／Vite 工程以适配平台发布，纯规则和图文内容仍独立于框架。此前 React + Vite 的分层原则保持，运行包装不是另建一套 Unity 客户端。

配图采用两张古风像素场景和一张非像素林晚立绘。客栈使用坊市外景作地点氛围配图，古道复用秘境山景；不把复用图声称为四张独立场景图。

NPC 与玩家共用修为收益、阈值、突破概率和突破结果处理；NPC 筑基占用三日并记录进行中的尝试。非致命石傀遭遇不会触发复杂模式终局；复杂模式保留寿元终局，更多危险遭遇尚未开放。
