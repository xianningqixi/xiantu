# 地图与残碑寻源主线验收

本轮将游历入口改为本城地图：地点、实际在场人物、当前事件和下一程路线放在一起。主线「残碑寻源」负责引导成长和远行，四卷支线仍按所在地点、人物与时间触发。主角始终是玩家创建的角色。

## 实现范围

| 地域 | 人物线索 | 实地核查 | 成长与下一程 |
| --- | --- | --- | --- |
| 青石坊市 | 周安辨认碑背水纹 | 听雨客栈查旧驿图 | 炼气二层，3 日到临江 |
| 临江城 | 裴姒提供渡口旧账 | 临江商道核对车辙 | 炼气三层，4 日到青岚 |
| 青岚山城 | 江照雪提供猎人阵图 | 问道客舍核对旧阵记录 | 筑基，5 日到霜河 |
| 霜河城 | 楚莲辨认藏书旁注 | 雪村核对证据并选择封存或公开 | 当前主线结束，可继续当地生活 |

八个节点使用独立主线事件记录，下一城要求前一程的实际线索，不要求消费三段支线。各卷引子仍从当地客舍问讯开始；人物只在自己的城镇内往来。主线对话需指定人物在对应地点且未在突破；各章实地核查需对话后至少两日，后三城对话还需抵达满两日。人物身故时改为当地客舍档案，参与者只记玩家。

初始证据有两条路径：原三人秘境战斗与结算，或炼气入门后独自到山门古道勘察两日。独自勘察没有数值奖励或战利品。地图展开、查看 NPC、滚动到事件和打开主线足迹都是只读操作。

剧情与条件来自 `content-packs/main-quest/story.json`，准备内容时校验引用并生成独立 `campaignLock`。未知锁拒绝；缺少主线锁的已知旧档通过现有 Worker 事务在副本上补锁、备份原档，完整落盘后才确认。原人物、时间、随机、资源、支线进度和旧经历保留；已访问城市保留通行权。世界仍为快照存档，没有新引入云同步或完整事件溯源。
