# C 期战斗与历练（第一增量）· 2026-10-20

范围：路线图 C 期 `docs/REDESIGN-2026-09-10.md` 3.4 的战斗技能、旅途遭遇与郊野探索三项。本轮只交付规则与最小 UI 接入，**未**交付可重复秘境、同行邀请基础版与浏览器验收。

## 已实现

- 战斗技能：`Actor.skills` 按境界槽位生效（炼气一 1 槽、炼气四 2 槽、筑基 3 槽），`battle` 命令新增可选 `skill`。
  - 青芒剑诀：按 `combat.skills.qingmang.damageMultiplierBp` 结算。
  - 御风步：本回合防御并取得下回合先手。
  - 冰心诀：回复配置比例气血。
  - 摄心术：目标下回合失去行动。
  - 太极归元：防御并反弹配置比例伤害。
  - 旧命令省略 `skill` 时仍默认青芒剑诀，旧战斗快照可选字段缺省可载入。
- 技能获取：新增 `learnSkill` 命令。客栈以 80 灵石学习御风步（炼气四）；入宗后以 60 贡献兑换冰心诀／摄心术／太极归元。道场快捷动作在客栈与宗门所在地显示可学招式。
- 旅途遭遇：主线结局后（`story.outcome !== "none"`）、非青石区域的跨区域旅途按每日 `travel.randomRoadEncounterBp`（12%）掷遭遇，最少炼气四；主干剧情章节不被打断；坊市／客栈／古道三点之间与青石区域不掷。山匪（玩家 ≤ 炼气五、境界 -1、2 人）与妖狼（1–2 人）复用既有 Fighter 战斗；简单模式非致命。胜利后战利品直接入包并抵达目的地，战败／撤退留在原地并按模式损失灵石、休养天数。
- 郊野探索：新增 `explore` 命令，仅森林／水域／山地郊野可用，1 日、地点冷却 2 日；按配置掷遭遇、凝元草、感悟或见闻，结果写入历程。
- 存档：`Battle` 新增可选 `kind`／`location`／`destination`／`loot`，`Actor.exploreDays` 记录地点冷却；校验覆盖新字段，旧档保持可选缺省。

## 第二增量（2026-10-21）：可重复秘境

- 主线结局后（`story.settledDay != null`）且没有已接受的续约时，`expedition` 转为自由历练：1–3 人、无需约定、战利品胜利后直接入包，返回坊市即解散同行。
- 敌人数量、气血、攻防随已完成次数按 `combat.repeatExpedition` 成长，上限 4 具；奖励灵石按成长比例提升，凝元草按概率掉落；仍保留路费、冷却与非致命规则。
- 战败／撤退回到古道且不计次数；`expeditionCount` 可选存档字段，旧档缺省可载入；战斗标题按遭遇类型区分（途中／郊野／秘境）。
- 新增 `tests/game/repeat-expedition.test.ts`（8 项）。规则测试总数 114。

## 第三增量（2026-10-22）：同行邀请基础版

- 新增 `inviteCompanion` 命令：朋友以上、同地点、无故事约定、队伍未满时可即时邀请，不消耗天数；首次邀请生成 `terms: "split"` 的平分约定，后续邀请扩充队员与名单。
- 平分约定下古道秘境 2–3 人可入山，沿用随次数增强的敌人与奖励；胜利时灵石与凝元草按队员当场平分，返回坊市自动结束约定并解散队伍；`disband` 也可提前结束。
- 故事约定的仍优先且保持原结算流程；`Agreement` 校验放宽平分约定的成员数（≥2、首名玩家、名单与队伍一致），故事约定仍锁三人。
- 新增 `tests/game/companions.test.ts`（10 项）。规则测试总数 123。

## 第四增量（2026-10-22）：D 期人物互动（论道／赠礼／传功）

- `discuss`（论道，1 日）：朋友以上且对方境界不低于玩家，+1 感悟、双方 +5 好感，每人 7 日冷却。
- `gift`（赠礼，0 日）：灵石 10／回春丹／凝元草 → +6／+8／+12 好感，每人 3 日冷却，物品与灵石不足时拒绝。
- `mentor`（请教，0 日）：挚友且对方境界高出 3 档，获得当前关口阈值 25% 的修为，每人 30 日冷却。
- 冷却记录在 `Relation.interactions`（可选字段），旧档缺省可载入；人物资料页新增论道／赠礼／请教入口与赠礼选择弹窗。
- 新增 `tests/game/social.test.ts`（9 项）。规则测试总数 132。
