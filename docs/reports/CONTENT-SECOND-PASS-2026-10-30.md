# 第二轮剧情与生活互动（2026-10-30）

## 背景

用户反馈「剧情和玩法太无聊，多增加剧情点和交互点，并丰富 NSFW」。

复核原始内容后确认两个结构性原因：

1. **每条线同构**：每位女主固定 12 步（引子→相识→再见→相知→心动→情敌→失手→初夜→双修→结契→守节），玩家做什么都一样。
2. **选择几乎不产生代价**：136 节点 362 个选项里 234 个只写 flag，效果种类只有 `progress / experience / meet`，既不给也不耗资源，选项只是换了行字。

外加一个更隐蔽的问题：`content-story.ts` 每个内容包只用 `.find` 取第一条可用节点，而春水、夏夜每包有三位女主，于是同屏永远只有一个人有戏；且主场景存在时旁支直接被 `return []` 丢掉，第二轮内容做了也看不见。

## 玩法侧的改动

| 改动 | 说明 |
| --- | --- |
| 效果语言扩展 | storylet 新增 `resource`（stones／grass／healing／insight，可正可负）与 `bond`（favor／trust／attraction）两类效果，进入 zod discriminatedUnion 与 capability 白名单 `resource.v1`／`bond.v1` |
| 条件语言扩展 | 事实白名单补 `player.grass/healing/insight/partner` 与 `actor.*.{favor,trust,attraction,realm,grievance}` |
| 同屏三条剧情 | 槽位上限 3；`spreadScenes` 先按「一人一条」再补齐，避免同一人占满 |
| 旁支可见 | 主线不再挤掉旁支：主线占主位、旁支进旁支栏，选项一并平铺进行动区 |
| 三种新互动 | 闲谈（1 日冷却，好感＋信任小额）、切磋（4 日冷却，双方耗血、胜负有感悟）、同游（5 日冷却，需在野外，信任与感悟） |
| 关系链松动 | 剧情里的照应、交心、回礼、天亮都会真给信任，`chatTrustGain` 让闲谈也能积累；不再是「要交情才能共事、要共事才有交情」的死锁 |
| 约定只约束失约者 | `companyReason` 原先一律拦下「有约定在身」，改为只拦住约好同行却不跟上的人 |

## 内容侧的改动

四卷各补五位女主的五个第二轮节点：**差事（errand）、交心（confide）、回礼（return-gift）、再夜（night-2）、天亮（daybreak）**，共 62 个节点、约 3.6 万字，其中 62 段 `explicit`（250–400 字）。

- 差事会真的花钱或货物（-20 至 -25 灵石、2 株凝元草、1 颗回春丹），换好感与信任；回礼则倒过来给物资。
- night-2 各不相同：药铺柜台、值夜哨棚、柴棚隔墙、雪堵楼门、山神龛、库棚隔板、冒雨下山、收摊楼上……与各自的初夜场景不重样。
- 每个节点都有空 `effects` 的退出项，玩家可以不接这条线。

## 测试

- `tests/game/extensions.test.ts`：resource 扣减缺货整笔回滚、bond 目标必须在 participants、缺无代价退出项要被拒。
- `tests/game/spread.test.ts`：同人不重复占槽、上限生效、排序稳定。
- `tests/game/social.test.ts`：闲聊／切磋／同游的门槛、冷却、耗日与收益。
- `tests/browser/second-pass.spec.ts`：真实 UI 走到两人同屏，断言旁支正文非空、署名互不重复；night-2 在「标准」档折叠、「含蓄」档隐藏。

结果：规则测试 167 项、内容 8 项、UI 3 项、浏览器定向 2 项全过，`npm run verify` EXIT 0。

## 已知限制

- 62 个新节点仍是线性分支，尚未做跨卷交叉（例如春水线的选择影响秋灯）。
- 同屏上限固定 3，未按屏幕宽度自适应。
- CG 仍复用既有构图，night-2 没有专属图。
