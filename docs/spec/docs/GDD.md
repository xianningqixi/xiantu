# 修仙 Web 图文 RPG：可执行玩法基线

版本：V0.1.1；配置版本：`prototype-0.1.1`；日期：2026-09-06。  
状态：供下一阶段编码和验收使用的设计，尚未实现、部署或经过游戏试玩验证。  
本文件以当前可见记录和 Web 修订稿为依据，不声称补齐了未提供的原规划前二十四节。

## 1. 决策边界

**已确认的产品要求：**Web 页面；每幕文字与配图；玩家在自行演化的修仙世界中生活；首批约四十名 NPC；Seed 可复现初始世界；资质可无限重掷；三件专属法宝三选一；简单与复杂模式；最多三人队伍，主角可手动、NPC 自动，也可全自动；好感、信任、吸引与可追溯记忆；凡人到炼气再到筑基；突破存在失败风险；玩家和 NPC 突破失败均不致命，可损失修为、严重时可跌境；复杂模式在其他场景真正死亡后本局结束。

以前确认的古风美术方向继续有效。Web 不再要求像素小人行走和碰撞；背景是否继续像素或改为非像素插画，正式素材扩充前通过样例决定。精细非像素古风立绘仍可使用。

**下面 D 编号的内容是为了开工给出的原型默认，不是用户逐项确认的最终设计。** 实现者直接按默认执行，不必把每个普通配置值重新提交确认。改动硬约束必须回到产品决策；调整默认数值则记录试玩原因、修改配置及相应验收。

所有可调数值的唯一执行来源为 `content/prototype-balance.json`。本文的数字示例用于阅读，冲突时先修正文档或配置的一致性，不允许代码另藏一套数值。概率使用整数万分比 `bp`，范围由 `probabilityScaleBp` 定义；所有修为、物品数量和关系值为整数。时间用游戏日，不用现实日期计算进度。

## 2. 玩家一轮在做什么

玩家读懂当前处境，选择一个有明确代价的行动，看到人物或世界发生变化，再决定继续交往、探索或成长。主循环为：

**坊市获得机会 → 修炼到可同行 → 商定分配 → 秘境遭遇 → 分配与关系后果 → 修炼或筹资 → 重逢看到记忆 → 准备并尝试筑基。**

成长机会不依赖重点人物故事成功：拒绝林晚、探索撤退、违约后失去她的信任，都不会让功法、劳务、修炼或购买突破丹的入口消失。复杂模式的实际死亡属于明确结束状态，不能伪装为普通任务卡住。

切片终点是完成筑基尝试并形成一段有后果的共同经历。失败后提供再次准备的路径；**不要求每个试玩者第一次筑基都成功，也不为演示暗改概率。** 成功筑基后进入可继续浏览与交往的阶段结束提示，不开放金丹任务。

### 2.1 每幕页面和操作约定（D-01、D-12）

- 顶部显示地点、游戏日、境界和当前重要限制；详细背包与属性另开面板。
- 每个主要场景包含有效配图。连续对话可以复用背景，人物表达通过表情和文字变化；每次点选不必重新生图。
- 行动按钮显示已知天数、物品消耗、条件和显著风险。条件不满足时解释原因；检查档案、设置、历程不推进时间。
- 当前操作结果明确写出已经发生的资源、位置、状态与关系原因变化。尚未落地的交涉只写“提议”，不能写成“已经约定”。
- 历程只读；回看旧图文、刷新、返回和重开页面不能重发奖励。
- 手机采用单列，文字可选择，按钮可触摸和键盘操作；图片加载失败显示同一身份的占位和替代文字，不阻断选项。
- 玩家不需要看完整世界日志。修炼或闭关后优先呈现少量可知熟人动态，允许展开详情。

### 2.2 地点与旅行（D-02）

| 地点 ID | 用途 | 常驻或可用入口 |
| --- | --- | --- |
| `LOC_MARKET` | 坊市与初识、交易、重逢 | 劳务、商店、在场人物 |
| `LOC_INN` | 修炼、休息、查看承诺 | 免费入门功法备用入口、基础修炼、闭关 |
| `LOC_GATE` | 出征准备与安全撤离落点 | 组队检查、出征、返回坊市、临时劳务 |
| `LOC_RUINS` | 秘境节点与战斗、分配 | 遭遇、撤退、战利品处理、返回山门 |

旅行边见 `travel.routes`。坊市与客栈位于同一聚落，切换不耗日；坊市至山门、山门至遗迹各消耗一日。进入秘境的出征命令在山门校验人数与条款、现付报酬并推进到遗迹。回程依次经过山门和坊市，总时耗由两条边相加，不以“回家”按钮漏扣一段。

出征那一日包含本次遭遇的时间预算，战斗回合本身不额外增加世界日。出征参与者在该日被占用，不能同时劳务或日常修炼；战斗暂停期间世界也暂停。世界按日结算只存在一个入口，不能旅行扣一次、战斗结束再扣同一天。

## 3. 创建角色与初始世界（D-03、D-05、D-11）

创建界面包括姓名、男女选择、外貌配置、资质、无限重掷、三法宝三选一和模式选择。资质原型先用单一整数分数，影响每日修为与大境界突破加成；不在切片期添加未定义的灵根克制表。外貌先是稳定配置数据与人物图引用，不要求原型制作全量换装素材。

角色创建完成时一次性保存完整结果；重新加载不重掷。资质重掷使用独立角色创建随机流，不能改变同一世界 Seed 的 NPC、地点和社会关系；仅用同一个 Seed、不锁生成器和内容版本，不作跨版本完全相同的承诺。

初始 NPC 数量包含林晚与周安，不是在普通 NPC 数量之外再额外增加。两人采用固定身份模板，其他人使用 Seed 生成。每个 NPC 至少有姓名、性别、出生游戏日、年龄派生值、外貌 Seed／图像引用、性格、资质、境界、归属势力、位置、目标、关系和生死状态。具体势力和性格枚举由内容注册表负责；本切片不需要建立可玩的宗门经营系统。

林晚初始炼气高层，周安初始炼气中层；两人都有固定回坊市的日程。接到同行／护法任务后占用时间和位置必须真实变化；未接到时继续遵守日级调度，不永远冻结在等待玩家的状态。正式进入事件时检查当前境界和目标：林晚已筑基时，其用药动机改为巩固境界；已经接受的本次凝元草承诺不会自动作废。

本版不生成师徒标签；师徒系统以后必须定义修炼阅历、双方资格与设定依据，再加入生成器，不能仅凭随机年龄连边。普通 NPC 死亡保留身份和历史引用，不能用新 NPC 复用死者 ID。首版日常 AI 用规则优先级，不调用语言模型。

### 3.1 三件法宝原型

| ID／临时名 | 最小效果 | 边界 |
| --- | --- | --- |
| `ARTIFACT_FOCUS`／定心佩 | 每日修炼增加固定修为 | 对应 `artifacts.ARTIFACT_FOCUS`，不改变随机流 |
| `ARTIFACT_WARD`／归途符 | 提高全队撤退成功率 | 封顶，不保证绝对安全，不把突破改为致命 |
| `ARTIFACT_BOND`／同心绳 | 玩家履行有效承诺时增加额外信任 | 对同一承诺只触发一次；不能无条件控制 NPC 或抵消违约 |

法宝不可同时选取或在创建后免费反复切换。NPC 共用培养和战斗规则，玩家法宝只是同一规则中的拥有者修正项。

## 4. 不会断资源的最小循环（D-04）

| 行动／资源 | 入口与规则 | 防卡死措施 |
| --- | --- | --- |
| 入门功法 `ITEM_MANUAL` | 初识林晚可一次赠送并学习；客栈提供无 NPC 前提的备用领取学习入口 | 两入口共享角色终身 claimKey；绑定、不可出售；学会后保留永久知识标记 |
| 灵石 `ITEM_SPIRIT_STONE` | 坊市、客栈、山门均可做无风险劳务 | 不收报名费，不要求功法、关系或装备，不因钱为零关闭 |
| 基础修炼 `METHOD_BASIC` | 学会功法后，在安全地点选择时长 | 免费；不要求丹药、护法或队友 |
| 灵石修炼 `METHOD_SPIRIT_STONE` | 每个实际结算日扣对应灵石，增加该日修为 | 开始前检查全部预算；提前出关未执行的天数不扣款 |
| 休息 | 安全地点免费恢复生命并推进时间 | 无负债、饥饿或房租循环；重伤不剥夺免费休息 |
| 复元丹 `ITEM_HEALING_PILL` | 商店购买，战斗或战外按规则使用 | 没钱时可以先休息；药物不是继续游戏的必要门票 |
| 筑基丹 `ITEM_BREAKTHROUGH_PILL` | 商店直接购买，或凝元草加灵石兑换 | 没有探索胜利也能通过劳务购买；突破也允许不用丹药 |
| 凝元草 `ITEM_NINGYUAN_GRASS` | 标准秘境胜利或商店购买 | 遗失或违约后仍有补偿路径；不会要求必须回到已关闭的唯一事件 |

原型不做售卖、物品耐久、每日生活费、负债和随机商店缺货。当前目的是验证探索与人物关系，扩经济复杂度须有试玩依据。商店和兑换必须原子扣物、发物；余额不允许为负。

玩家最低可行路径：独立领功法、免费修炼到凡人阈值、尝试入气；失败继续修炼。炼气后可做劳务付同行费用，再探索；也可继续免费修炼和劳务购买丹药后尝试筑基。任何时点钱耗尽，只要仍存活且不在未解决的战斗中，都存在回安全地点或战败救援后的劳务／休息入口。

## 5. 修炼、突破和恢复（D-03、D-06、D-07）

### 5.1 修为与小层

每个完整修炼日的增益为：

`gain = realmDailyBaseGain + floor(aptitude / aptitudeGainDivisor) + methodAdditionalGain + ownedArtifactGain`

只在该日真正执行修炼时增加；旅行、劳务、被占用的护法和战斗日不兼得。修为达到当前境界阈值后停止累加，溢出不带到下一层；突破界面明确提示“当前层已满”。凡人入气需要功法知识和相应修为。玩家和NPC均在完整修炼日结算时自动执行炼气小层晋升，不掷成功骰；大境界保留失败风险。

小层升级和大境界成功后，当前层修为归零，更新历史最高境界。境界提升带来的生命上限增加只补增加的上限差额，不免费抹去既有伤势。下降时当前生命钳制到新上限。筑基初阶是本版顶层，只保留有上限的修为记录和正常人物互动，不显示一个永远无法完成的下一境界突破按钮。

### 5.2 成功率与准备

凡人入气使用 `advanceRules.MORTAL.baseSuccessBp`，不额外堆叠护法和丹药。筑基成功率使用同一服务给出预览和实际值：

`successBp = clamp(baseSuccessBp + aptitude * aptitudeBonusBpPerPoint + validPillBonusBp + validGuardianBonusBp, successFloorBp, successCeilingBp)`

丹药与护法都可不选。原型护法须存活、可行动、在同一安全地点、境界不低于突破者，且满足关系门槛；不能在别处同时组队或闭关。护法接受后预留完整时长，无随机中途离席；死亡或其他强制外部终止作为独立中断原因处理，不能悄悄更改显示过的成功率。

开始前展示概率、耗时、消耗时点、普通失败和严重失败的可能后果。确认时占用行动、消耗选用丹药、冻结准备快照；结束时按保存的快照掷骰并原子结算。退出页面不重置尝试、不退丹药、不重掷。原型突破尝试不允许自愿中断；普通闭关允许在完整日检查点提前结束。

用 `r` 表示该随机流输出的 `[0, probabilityScaleBp)` 均匀整数；`r < successBp` 成功。仅在失败时另取一次条件骰，决定是否属于严重失败。配置中的严重失败比例是**失败之后的条件概率**，不是额外叠加到所有尝试上。例如不带准备、资质居中的筑基总成功率约七成时，严重失败占全部尝试的概率仅为剩余失败率再乘条件比例。

### 5.3 失败和恢复边界

- 普通失败：保留当前境界；从当前层修为扣 `ceil(currentExperience × failureExperienceLossBp / probabilityScaleBp)`，下限为零。生命不扣除，不添加可间接致命的突破伤势。
- 严重失败：只有存在可下降的炼气小层时，下降配置指定的小层数并把新层修为归零；保底炼气首层。本切片具体作用于炼气高层尝试筑基失败，不将凡人入气失败降为死亡，也不让已入气者变回凡人。
- 凡人入气失败仍是凡人，属于尚未取得新境界；首次筑基失败不使角色跌破此前已取得的炼气大境界。筑基成功后的后续大境界突破本版不开放，不臆造跨大境界下降规则。
- 恢复：按同一每日修炼和小层晋升规则重新爬回此前层次，无付费解锁、额外永久资质损失或随机恢复门槛。历史最高境界与第一次入气奖励不回滚，恢复时不重复发放一次性奖励。
- 玩家和 NPC 调用同一规则；自动修炼的 NPC 也会失败、损修为和恢复。死亡原因枚举不得存在 `BREAKTHROUGH_FAILURE`。

### 5.4 闭关与世界

短修炼和长闭关使用同一日级函数。长行动在完整游戏日边界保存剩余日数与已结算消耗；暂停计算不等于角色已经出关。自愿提前出关只停止未来日数，不追回已过时间或已耗资源。

林晚的自主决策默认优先获得凝元草、兑换或购买丹药后再尝试筑基，这是可读取的个人准备偏好；她仍可劳务、修炼、移动，不为故事冻结世界，也不改变她调用的突破校验和概率规则。accepted仅保留条款，不冻结日常；实际旅行、探索、护法期间才占用。闲置队友可在同地点修炼、劳务和休息，不能未经离队事件独自移动。

本版护法与突破准备不允许被 NPC 普通行动覆盖。安全地点没有随机袭击；游戏时长过长导致独立寿命终止时，应以 `OLD_AGE` 事实终止后续行动，并明确属于寿命规则，不能记成突破失败。未成年内容不进入本原型关系路线。

## 6. 图文战斗、撤退与模式（D-08、D-09）

### 6.1 一个完整回合

每轮开始按速度降序排队，同速按稳定角色 ID 升序。排序快照在本轮内不改；每个尚可行动角色轮到时执行一次行动。已倒地或死亡角色跳过；角色倒地不等于已经死亡。全队没有可行动者时按遭遇与模式进入败局结算。

主角选择普攻、技能、防御、丹药或全队撤退；NPC 使用相同合法行动集合自动决策。自动模式只是替玩家选动作，不能额外行动、忽略物品消耗或读到不允许玩家获得的信息。每个完整回合提交检查点，动画快慢和跳过战报不影响结果。

原型普通攻击伤害为 `max(basicAttackMinDamage, attack - targetDefense)`；技能先对攻击乘倍率并向下取整，再减防御、应用防御减伤。防御效果持续到本人下次行动开始，跨回合有效，最终伤害仍保留最低伤害。原型不启用暴击、闪避或复杂元素相克。

四个技能槽保留，首版只解锁一个“凝气击”占位技能，其余显示未解锁，不制作假可点技能。冷却按本人行动轮次记录：使用后接下来配置数量的本人行动机会不可再次使用，防御或丹药同样会消耗行动机会。丹药按上限比例恢复并消耗库存；NPC 从各自库存使用，不能默默吃掉玩家的药。

自动策略依次考虑危急撤退、能救急的丹药、可用技能、最低生命敌人的普攻；同类目标同值以 ID 排序。两种自动控制共享此顺序。手动界面仍允许玩家作出合法但次优的选择。

撤退判定由当前行动者请求，扣其本次行动机会；成功则整支队伍退出，失败继续本轮。已倒地者可随全队撤离，按撤退恢复配置回到最低可继续行动的生命值，不在“已经安全撤退”之后暗判死亡。回合上限触发可解释的强制非致命撤离，不无限战斗。

### 6.2 战败与实际死亡

| 情况 | 简单模式默认 | 复杂模式默认 |
| --- | --- | --- |
| 本次教学秘境战败 | 救援到山门，少量灵石损失、恢复日和生命恢复 | 同样救援，经济／恢复代价稍高；明确非致命 |
| 主动撤退成功 | 无额外战败扣钱，无未取得的胜利掉落 | 相同规则 |
| 将来显式致命遭遇战败 | 玩家按救援规则处理 | 若主角已倒地，产生实际死亡并结束本局；否则按该遭遇退出规则结算 |
| 突破失败 | 仅执行修为／跌境规则 | 相同；不得产生死亡 |
| 普通 NPC 死亡 | 由遭遇、寿命等世界规则决定 | 相同，不由玩家所选难度凭空改 NPC 生死 |

致命遭遇在本切片内容默认关闭，不能把一个普通“探索”按钮暗藏为死亡抽签。后续开启时，进入前显示风险并要求玩家明确选择；死亡结果必须有独立验收夹具。**复杂模式结束规则需要在领域测试中覆盖，但首条非致命教学故事本身不宣称已经验证真实致命内容。**

战败损失按当前余额取比例向下取整，不负债，不丢唯一功法、不摧毁法宝。非致命故事胜利时，存活倒地成员按combat.nonlethalVictoryDownedHpRestoreBp恢复到至少1HP，再释放战斗占用并允许返程；与掉落一并只结算一次。战败移动和恢复日由一次终局命令提交；此时行动占用释放，队伍关系与待结算承诺继续按当前行程处理。死亡后停用所有改变世界的玩家命令，保留结局、历史、导出或另开新局入口，不在死档中继续修炼。

## 7. 关系、事实与承诺（D-10）

### 7.1 关系的三层

好感和信任范围为负到正，吸引范围从零起；具体边界见配置。每条值表示 A 对 B，不能因 A 变了就假定 B 同步变化。原型普通社交和承诺不自动增长吸引；它作为已确认的独立维度被完整保存和展示，恋人／道侣／夫妻路线本切片尚不开放。

第一层为数值；第二层为关系标签；第三层为具体事件、知情记忆与共同经历。朋友、挚友通过配置阈值和足够经历派生；敌对由明显负面关系派生，仇人须有显式严重怨恨事件。标签不能替代承诺事实。背弃重要约定后可立即撤销挚友资格，不因为旧好感仍高而无视违约。

亲密标签以后需要双方明确同意及身份规则，不达到吸引阈值就自动结婚；成人门槛属于当时关系资格，不用当前年龄倒推过去已发生的内容。

每次关系变化必须引用一个真实事件及评价者。普通世界事实不等于全部 NPC 自动知情；同队亲见、当事人告知等来源分别保存。未知秘密不进入 NPC 台词或 AI 上下文。

关键承诺、突破、死亡及重逢记忆长期保留；低价值重复日常可摘要或过期。记忆淘汰不删除相关物品归属、承诺状态和关键事实引用。重复处理相同事件 ID 不再增减关系。

### 7.2 承诺状态机

| 状态 | 进入条件 | 后续允许变化 |
| --- | --- | --- |
| `draft` | 有提议但条款或同意不完整 | 补条款、拒绝，或全部同意后 `accepted` |
| `accepted` | 三人已接受条款，但尚未出征 | 出征现付报酬后 `active`；出征条件永久无法满足则明确取消 |
| `active` | 已出征，合同覆盖本次探索 | 首株草出现则义务标记可履行，合同仍保持 active；分配后履行或违约；无草离开为 `not_triggered` |
| `fulfilled` | 约定物品实际转给指定人 | 终态，履约关系与记忆一次性结算 |
| `breached` | 到期不履行，或明确把到期物品分给与条款不同者 | 原违约保留，可增加一次补偿事实与 remediation 状态 |
| `cancelled` | 条件允许且双方达成取消 | 终态，不罚作违约 |
| `not_triggered` | 本次探索退出，始终没有出现约定的合格掉落 | 终态，不扣信任，不欠一株并不存在的草 |
| `impossible` | 如受领人真实死亡导致原条款永久不可履行 | 记录原因并进入明确处置，不能自动当作恶意违约 |

没有当前合同时，页面投影状态为 `none`；它不是持久化合同状态。到期／可履行是 active 合同中义务的标志，不增加一套冲突的 DUE 状态。离队或暂时不在场不是永久客观不可能，承诺继续存在。本例不设模糊现实时间期限，作用域为唯一 `expeditionId`。有待分配草时，玩家可以明确违约，但不能通过退出页面、偷偷离队或返回地点绕过结算；需要显示违约后果的确认步骤。

补偿使用真实物品转移，一次性增加有限信任；不把 `breached` 改写成 `fulfilled`，不抹掉林晚曾经受骗的记忆。补偿后可以按更低的严格邀请信任门槛再谈同行，但凝元草交由确定分配规则执行，违约分配选项关闭；玩家可拒绝这份新合同。初次信任不自动完全恢复，严格合同的改变在接受前展示。

### 7.3 第一条故事的具体合同（D-11）

使用单次探索的明确示例：**本次获得的第一株凝元草归林晚；其余战利品归玩家；林晚、周安各收固定灵石出征报酬，在出征时现付一次。** 这是演示合同，不能当成所有秘境的永久分配制度。以后“平分”需要另写可除货币和不可分物品规则，本合同不使用含糊平分。

出征报酬必须检查并转移玩家真实库存，去重键包含探索 ID 与收款人 ID；撤退不退已付报酬。没有达成三人合同或余额不足时，解释原因并保留劳务入口。

标准胜利掉落见配置；先进入待分配池再按玩家选择转移，不能先塞入玩家背包再检查草是否被用掉。没有取得草的撤退走 `not_triggered`。有人离队、目标改变和受领人死亡分别按上述状态处理，不把所有异常都写成同一条责怪玩家的对白。

履约使林晚更信任并更愿意再同行；违约降低信任、拒绝照搬旧条款并出现补偿入口。周安只依据自己的报酬和亲眼见到的事件评价，不能因为林晚收到草就机械复制她的全部关系变化。

返回坊市、完成本次结算后开始重逢等待计时。达到配置游戏日再进入坊市并确认林晚在场，选择对应已发生事实的台词；未满等待时长给普通互动，不能用现实等待凑时间。

## 8. 世界演化的最小执行范围

每日先处理生死和长期占用，再裁决抵达、资格与可执行行动，之后统一应用修炼、劳务、社交等后果。优先级和稳定顺序由 TDD 确定，不能直接依赖对象遍历顺序。地点以唯一位置状态表示；旅行或同行占用不额外复制角色。

普通 NPC 的最小行动是修炼、筹资、移动、社交、休息；符合条件可以尝试大境界。首个版本关闭随机路遇与普通 NPC 后台致命战斗，先验证死亡生命周期和固定遭遇，再通过独立任务开启更复杂冲突。M3 的冲突能力仍需用启用后台冲突的测试夹具验收，教学切片的关闭配置不等于删除该里程碑要求。关系变化与非致命意见冲突可记录为事件，不要求首版实现宗门战争。

寿命是明确的游戏日终止条件，按现境界提高可用上限。简单模式玩家达到寿命边界按配置保留可行动状态并显示范围提示，不产生玩家死亡；复杂模式独立寿命死亡在临界前显示预警，并遵守结束规则。两种模式不影响 NPC 的同等修炼和突破规则。

固定 Seed 长模拟要检查死者无行动、身份可追溯、地点唯一、资源不负、承诺引用合法、离开势力后资格消失、突破不会产出死亡。压测规模只用于规则测试，不把压测 NPC 数量误写为首局默认数量。

## 9. AI 和美术的交付边界（D-12、D-13）

所有关键成长、同行、战斗、分配、补偿和重逢都必须能通过固定按钮完成。自由交涉作为后置增强，仅把玩家自然语言转成有限结构的候选条款；真实接受条件和物品／队伍写入仍由规则校验。未解析清楚的“给你”“平分”“陪我”进入草案，不能即刻执行。

世界不因模型超时、生图失败或网页关掉而前进。模型不能直接指定修为、境界、信任分数、生成物品或解除死亡。图片和立绘只根据既有身份与事件绑定；生成式叙述不能反向创建一个未发生的“救过我”的历史。

原型采用素材清单和占位图；每位重点 NPC 保持稳定面孔。素材数量、单幕字数等预算见 `presentation`。背景像素／非像素风格最终拍板前，不采购或批量制作完整正式素材。当前包提供设计和内容规范，不宣称已经制作这些图片。

## 10. 范围和验收入口

V0.1 必做：角色保存、确定性世界、日级行动与共用修炼规则、关系／承诺／记忆、图文事件、轻战斗、闭关、一个人物故事与恢复路径。M8 完成后可开展固定选项版本的内部试玩；本执行包的完整交付包含 M9 的 AI 接口、校验和回退，再按 M10 集成验收。AI 为玩家可关闭的能力；无 key 时固定选项仍能完成基础闭环。开发可先用 mock，真实供应方未测试必须单列，不能计为已通过。

暂不做：金丹以上、完整恋爱路线、宗门经营、生产链、多人世界、云同步、实时世界服务器、每次操作实时生图、完整 Mod 编辑器、可任意执行脚本的内容包。保留稳定内容 ID 和版本，不预做整个未来引擎。

| 可执行验收情境 | 必须看到的结果 |
| --- | --- |
| 重掷很多次再创建与未重掷创建 | 同世界 Seed／版本产生相同初始 NPC 与地点，玩家资质按独立随机流变化 |
| 玩家零灵石且不接受林晚 | 仍能领取功法、免费修炼和劳务，存在入气与准备筑基路径 |
| 丹药开始后刷新并恢复 | 不重复扣丹、延长时长、换概率或重掷结果 |
| 指定成功／普通失败／严重失败随机夹具 | 修为和小层按配置变化，生命不受突破伤害，无突破死亡事件 |
| 秘境胜利履约与另存档违约 | 库存去向、信任、后续邀约条件和重逢台词均不同且可追溯 |
| 未获得草便撤退 | 承诺 `not_triggered`，不会凭空欠草或扣违约信任 |
| 违约后补偿再见面 | 真实扣补偿物品，恢复部分信任，但旧违约记忆仍存在 |
| 连续模拟与中途存读档续跑 | 最终规则状态、随机状态与重要事件一致 |
| 简单战败与复杂真实死亡夹具 | 前者能恢复继续；后者仅在独立真实死亡后结束；突破失败不经过死亡分支 |
| 林晚已筑基、离开或无法同行 | 叙述反映现实；主成长仍可进行，缺席时显示等待／其他行动而非假在场 |
| 图片或 AI 不可用 | 固定选项可完成基础体验；无重复资源与时间结算 |

实现与测试任务编号以 `docs/TASKS.md` 为准，技术协议以 `docs/TDD.md` 为准。验收需要实际报告测试环境和结果，本文中的目标不是已通过的测试。
