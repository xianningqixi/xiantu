# 公开测试的合成世界

当前存档测试通过 `../synthetic-world.ts` 在内存中创建全新的测试角色，调用生产引擎完成相识、约定和日常演化。生成器使用独立的固定测试 Seed 与“自动测试角色”资料，不读取任何浏览器导出、原测试存档或用户个人数据。

自动生成的第 9 日和第 40 日世界用于导入、备份、回滚和过期写入测试。它们是当前规则生成的测试状态，不宣称是旧发布版本的浏览器快照，也不宣称第 40 日角色已筑基。

自动审批拒绝公开上传此前浏览器导出的 JSON 快照。因此公开仓库不包含这些被拒绝的文件，也不通过编码、重建原快照或历史包间接发布。历史 QA 报告保留当时的验证事实；接手者可在自己的测试浏览器重新导出测试进度。不要提交真实玩家存档。
